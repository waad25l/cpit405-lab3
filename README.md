# CPIT 405 – Lab 3 Starter Template

## Lab Focus

This lab focuses on **CSS styling**. The HTML structure is provided for you.

Your main task is to create a new file named:

```text
style.css
```

and use CSS to transform the provided HTML into a professional personal CV web page.

## What You May Edit in `index.html`

You may update the content to match your own CV, including:

- Your name
- Job title / student title
- About Me text
- Education information
- Skills
- Projects
- Email
- GitHub link
- LinkedIn link

Try to keep the overall HTML structure unchanged unless necessary.

## CSS Requirements

Your `style.css` must demonstrate all of the following:

- Element selector
- Class selector
- ID selector
- Descendant selector
- Font styling
- Background color
- Margin
- Padding
- Border
- Hover effect
- At least one media query for responsive design

## Recommended Workflow

1. Open `index.html` using Live Server.
2. Create `style.css` in the same folder.
3. Start with basic page styling.
4. Style the header and navigation.
5. Style the CV sections.
6. Style the skills and project areas.
7. Add a hover effect to links.
8. Add a media query for smaller screens.
9. Test your page using Developer Tools.
10. Publish your final CV using GitHub Pages.

## Final Folder Structure

```text
lab-3/
├── index.html
└── style.css
```
